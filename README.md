Ferramenta realizada durante estudos de Cibersegurança.
Desenvolvida em Python para geração de senhas aleatórias utilizando o módulo secrets, com suporte a diferentes políticas de composição.
Permite selecionar conjuntos de caracteres e gerar credenciais de forma automatizada utilizando aleatoriedade criptograficamente segura.
O projeto demonstra conceitos de geração segura de credenciais, manipulação de strings, funções, entrada de dados e aplicação de princípios básicos de segurança da informação.

Tecnologias: Python · secrets · string · CLI · Cryptographically Secure Randomness · Password Generation
